# Supplementary Fig. 13 assembly

- `supfig13.pptx`: approved editable PowerPoint assembly with panel letters.
- `suppFigThirteen.pdf`: cropped PDF uploaded to the manuscript.
- `assembly_manifest.json`: panel sources, current artifact hashes and native
  dependencies.

The final figure was assembled in PowerPoint, exported as PDF and cropped.
Source materials are owned by
`supplement/tivelo_gene/figures/`. A/B use the compact two-row material, C the
simulation root pairs, and D the paired bone marrow DPT and metric row.

Native refit H5ADs are available through the [published result downloads](../../../data/RESULT_DOWNLOADS.md).
Match each recorded SHA-256 to the [member index](../../../data/result_member_manifest.tsv),
then use its package ID in the [package index](../../../data/result_package_manifest.tsv).
