# Paper figure assembly assets

Every materialized panel under this directory is a regular repository file.
`assembly_manifest.tsv` records its paper figure, panel, canonical source,
materialized path, and SHA256; missing independent sources remain explicit.

Figure 6 has 16 materialized source panels, including Dynamo(label data) in
organoid panel E. Its composite is `../figSix.pdf`, recorded separately in
`../fig6_composite_manifest.json`. Figure 7 retains the repository-baseline
`../figSeven.pdf`; no independent whole-panel source is recorded. The old
kinetics Figure 5 material is kept in the archive and has no active assembly
aliases.
