# Archived non-online veloAE drafts (2026-09-27)

These files were generated before the online `merged.tex` settled on the
current Supplementary Figure 11 contract. They are retained for historical
traceability only and are not manuscript sources.

The active online figure has two panels: A is the paired PCA summary and B is
the 14-dataset shared-axis projection plate. The archived material contains an
obsolete A/B/C assembly, an obsolete 4×4 projection layout, or the earlier
three-asset handoff bundle. It must not be used to build or cite the current
paper figure.

The active sources remain under `supplement/veloae/` and
`results/ppt_assets_final/`; the repository assembly map points to the active A
and B source PDFs.
