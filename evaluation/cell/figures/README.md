# Cell-level figures

The five-metric summary and CBDir-HD panels are generated from
`../results/cell_metrics.csv` and `../results/cell_metrics_supplementary.csv`
by `../plots.py`.

Figure 2 stream montages use `../plot_cell_stream_panels.py`, the Source Data
display arrays and the native output selections in `../inputs.tsv`.
`stream_generation.json` records their numerical sources and output hashes.
The real-data examples use a 3×7 montage with a common stream crop, fixed
column/body/header proportions and Liberation Sans headers. Annotated
reference tiles retain their complete panel geometry.
The two `references/` images retain the annotated prior trajectory geometry.

The repository-root paper composites use author assembly and PDF export.
