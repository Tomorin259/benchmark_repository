# Kinetics figure assets

The paper panel assets for the kinetics-recovery experiment are in paper/.
The plotting code is in ../plotting/.

| Internal system ID | Display name | Figure 5 panels |
| --- | --- | --- |
| `rpe1` | `rpe1` | A--D |
| `organoid` | `organoid` | E--F |

The directory and file names intentionally retain the internal IDs so that
they continue to match `config.json` and the external artifact map.

The Dynamo curve in the RPE1 quantitative panels is the labelled-data result
(`Dynamo(label data)`), not the global RNA-seq configuration label.

figure5A_rpe1/ contains the five `rpe1` (RPE1) stream assets used for Figure 5A. The
DeepKINET asset is regenerated by plotting/streams.py from the current seeded
H5AD and the canonical RPE1 reference embedding; the other four assets remain
the confirmed manually selected panel inputs.

figure5E_organoid/ contains the three confirmed `organoid` stream assets.
The remaining Figure 5 panels and their plot data are generated by the
kinetics plotting module from the mapped legacy CSV inputs. In particular,
both RPE1 kinetic-class panels are recomputed from alpha/gamma trajectories;
their count and per-gene membership tables are kept under `plot_data/`.

The paper-level composite is stored at the repository root under figures/.
