# Simulation input generation

Benchmark scores use the fixed simulation inputs distributed with the
[data release](../../../data/README.md#canonical-inputs). The generator creates
additional simulation realizations.

`generate.py` is the public generation entry point for the three simulation
scenarios used by the gene-level benchmark. It contains simulation only;
preprocessing, dimensionality reduction, and plotting remain separate
downstream operations.

To fit methods on the three saved benchmark inputs, follow the nine
[simulation method commands](../../../methods/README.md#run-methods-on-simulations).
The [Gene evaluation guide](../README.md#recalculate-cbdir) then recalculates
CBDir and CosSim from the method outputs.

The scientific parameters live in [`config.json`](config.json), not in the
command line. The entries preserve the audited CellDancer 1.1.7 logic for
`murk`, `branching`, and `hybrid`. The branching BoostALL parameters are
`alpha1=5, alpha2=4, beta1=1, beta2=2, gamma1=5, gamma2=1`.
These values follow the canonical H5AD parameter layers. Simulator source
hashes and the parameter-source record are retained in `config.json`.

The generator requires cellDancer 1.1.7 and `setuptools<81`, which provides
`pkg_resources`. Run from the repository root with a relative output directory:

```bash
python evaluation/gene/simulation/generate.py \
  --scenario branching --output-root outputs/simulation
```

The output has the correct scenario-specific name (`sim_only_murk.h5ad`,
`sim_only_branching.h5ad`, or `sim_hybrid.h5ad`) and a sidecar
`*.invocation.json` containing its config hash, generator hash, output hash,
shape, dependency versions, random-stream policy, and canonical artifact ID.
The fixed input identities are indexed in [`artifacts.tsv`](../../../artifacts.tsv).
Randomness settings are recorded in `config.json` and each output's invocation
record.

## Velocity reference

[`truth/`](truth/) contains the paired noise-free `clean_u` and `clean_s`
states and their ODE velocities for the 10/20/40 evaluated genes in
MURK/branching/hybrid. The arrays use explicit cell and gene identifiers.
`velocity_u_true = alpha - beta * clean_u` and
`velocity_s_true = beta * clean_u - gamma * clean_s`; observation noise is
not included in this reference. `manifest.json` records source and array hashes.

Materialize the reference directly from the registered clean-state H5AD inputs:

```bash
python evaluation/gene/simulation/reference.py \
  --artifact-root /path/to/velocity-artifacts --output-root outputs/simulation-truth
python evaluation/gene/run_reference30_gene_cbdir.py \
  --artifact-root /path/to/velocity-artifacts \
  --datasets murk branching all --output-root outputs/simulation-evaluation
```

The evaluator retains every method's saved prediction and the veloVI coordinate
unit multipliers, and writes the complete 630-row comparison to an empty
output directory. `reference.py` validates reference shapes and identifiers
and aligns named cell/gene subsets for supplemental controls.

New datasets generated by `generate.py` retain `clean_spliced` and
`clean_unspliced` before the noise call and use those states for the ODE
velocity layers. This capture preserves the observed expression and random
draw sequence of the cellDancer call.

Full-expression upstream diagnostics require reference genes beyond the
10/20/40 evaluated genes. Generate that explicit scope in a separate directory:

```bash
python evaluation/gene/simulation/reference.py \
  --artifact-root /path/to/velocity-artifacts --all-genes \
  --output-root outputs/simulation-truth-all-genes
```

The all-gene option leaves the registered selected-gene reference unchanged.

## Canonical simulation inputs

The input distribution includes noisy observations, full-gene clean states and
ODE velocities. `reference.py` reads these layers with NumPy and AnnData.
`make_truth_reference.py` provides reconstruction from the source observations
with cellDancer 1.1.7 and the recorded configuration. Input and native-fit
source identities are listed in [source_provenance.tsv](../../../data/source_provenance.tsv).
